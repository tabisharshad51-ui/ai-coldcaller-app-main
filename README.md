# 📞 AI Cold Caller Dashboard

A lightweight lead-management dashboard built with **Python, Streamlit, and Google Sheets** for monitoring leads generated by an AI cold-calling workflow.

The dashboard gives sales teams a simple interface to view AI-generated leads and manage the output of an automated calling system without working directly inside spreadsheets.

---

## 🚀 Overview

AI-powered cold calling systems can generate a large number of leads, but the results still need to be organized and reviewed by a human.

This project provides a simple dashboard that connects directly to Google Sheets and displays lead information collected by the AI calling workflow.

The current implementation includes:

- AI cold-caller lead monitoring
- Google Sheets integration
- Simple Streamlit dashboard
- Lead table visualization
- Voice-agent readiness control
- Secure credential handling using local service-account credentials

---

## ✨ Features

### 📊 Lead Dashboard
View lead data stored inside Google Sheets directly from the Streamlit interface.

### 📞 AI Caller Integration Ready
The dashboard is designed to work alongside an AI voice/cold-calling workflow.

### 🔄 Google Sheets Synchronization
Lead data is retrieved directly from a connected Google Sheet.

### 🖥️ Simple User Interface
Built with Streamlit for a clean and lightweight web-based dashboard.

### 🔐 Secure Credentials
Google service-account credentials are kept outside Git version control through `.gitignore`.
